# Kareem Osama Abozaid — Portfolio

## ازاي تشغله من VS Code

1. افتح VS Code.
2. `File > Open Folder` واختار الفولدر ده (kareem-portfolio-advanced).
3. لو مش عندك إكستنشن **Live Server**، نزّله من الـ Extensions (Ctrl+Shift+X) هابحث عن "Live Server" بتاع Ritwick Dey.
4. دوس كليك يمين على `index.html` واختار **Open with Live Server** (أو زرار "Go Live" تحت في الشريط).
5. هيفتحلك الموقع في المتصفح على `http://127.0.0.1:5500` تقريبًا، وأي تعديل تعمله هيتحدث لايف.

## الملفات
- `index.html` — ملف واحد شامل كل حاجة (HTML/CSS/JS)، تجربة سينمائية بالـ Three.js: مجسم برونزي بيتحرك مع السكرول، شادر خلفية متحرك، وشرارات فرن. لازم اتصال إنترنت عشان يحمّل مكتبة Three.js والمجسم من CDN.
- `assets/` — صورة البروفايل والـ CV (PDF)
